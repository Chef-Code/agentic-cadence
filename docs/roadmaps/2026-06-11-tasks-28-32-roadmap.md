> **For agentic workers:** Use `docs/roadmaps/2026-06-11-tasks-28-32-roadmap.md` as the public planning artifact after Tasks 23-27. Implement each task on its own branch and update the living docs with evidence before merge.

**Goal:** Move Agentic Cadence from post-closeout planning and review-response planning toward exact operator-approved write-side bridges, without granting autonomous GitHub writes, merge, release, package-publication, distributed-lock, role-assignment, or continuous-loop authority.

**Architecture:** Cadence remains the governor. The next slices should preserve the existing plan-first pattern: prove local evidence, bind a reviewed write plan to exact operator approval, execute only the approved side effect, audit the result, then refresh evidence before recommending follow-up work.

**Tech Stack:** Python 3.11+, stdlib CLI, local JSON packets, append-only local audit evidence, Git, optional `gh` only for exact operator-approved GitHub materialization or explicit read-only evidence capture paths, `unittest`, GitHub Actions.

## Phase Ladder

Tasks 28-32 deliberately add only narrow, approved bridges after the existing
read-only and plan-only evidence gates:

1. **Phase 4 Git/PR bridge: Dirty commit materialization** - turn a reviewed dirty-worktree materialization plan into an exact local branch/commit only after target-bound approval.
2. **Phase 4 GitHub bridge: Dirty PR materialization** - push and create/update a PR from committed dirty materialization evidence only after approval and freshness rechecks.
3. **Phase 5 review bridge: Response write planning** - bind read-only review-response recommendations to exact PR body/comment write targets without writing.
4. **Phase 5 approved review writes: Response materialization** - perform only approved PR body/comment writes and audit them; do not resolve threads automatically.
5. **Phase 1/5 feedback closure: Post-write evidence refresh** - refresh saved PR/check/review-thread evidence after approved writes and emit a bounded next-action packet.

## Recommended Order

1. Task 28 creates the missing approved local commit bridge for dirty real-run output.
2. Task 29 binds that committed dirty evidence to the existing approved PR materialization boundary.
3. Task 30 turns read-only review-response recommendations into exact approval targets.
4. Task 31 executes only approved PR body/comment writes with audit evidence.
5. Task 32 refreshes PR/check/review evidence after approved writes before the next recommendation.

## Boundaries For All Five Tasks

- No autonomous branch creation, commit, push, PR create/update, review-comment write, or PR body update.
- No review-thread resolution until a later explicit slice defines its approval and audit contract.
- No paid review spending.
- No merge, release, or package publication.
- No continuous unattended loop or automatic retry of real executor invocations.
- No role assignment, agent-pool scheduling, GitHub issue assignment, shared runtime, or distributed lock claim.
- No named host adapter claim beyond generic local command evidence.
